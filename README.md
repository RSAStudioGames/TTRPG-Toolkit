# TTRPG Toolkit

Tabletop RPG Toolkit — a monorepo with a SvelteKit frontend and Go backend.

## Quick start

```bash
cp .env.example .env
make install
make build
make run
```

Open http://localhost:8080

For frontend development with hot reload:

```bash
make dev-frontend
```

See [docs/development.md](docs/development.md) for details.
